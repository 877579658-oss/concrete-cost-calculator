# 混凝土每方成本计算器

手机优先的静态 PWA，按每立方米配合比、单价、税率和可抵扣比例计算混凝土成本。所有输入只保存在当前浏览器，不上传服务器。

内置 C15、C20、C25、C30、C35、C40 六个强度等级，每个等级分别保存材料用量，也可添加自定义等级。材料的单价、税率和其他费用在各等级间共用，切换等级不会覆盖其他等级的配合比。

## 计算口径

- 含税单价：`含税金额 = 单价 × 用量`，`税额 = 含税金额 × 税率 ÷ (100 + 税率)`。
- 未税单价：`未税金额 = 单价 × 用量`，`含税金额 = 未税金额 × (1 + 税率)`。
- `可抵扣税额 = 税额 × 抵扣比例`。
- `抵扣后成本 = 含税金额合计 - 可抵扣税额合计`。
- 原材料用量可按 kg 或 m³ 录入；kg 对应元/kg 或元/吨，m³ 对应元/m³。
- 其他费用按元/m³ 录入。

可抵扣税额是理论值。实际抵减取决于合法有效凭证、用途限制和当期是否有足够销项税；本工具不判断这些条件，也不处理企业所得税、附加税和进项转出。

## 本地运行

需要 Node.js 18 或更高版本，无需安装第三方依赖。

```powershell
cd D:\Codex\2026-11-03\concrete-cost-calculator
node server.mjs
```

浏览器访问 `http://localhost:4173`。同一 Wi-Fi 下也可用电脑局域网 IP 加端口访问。

## 测试

```powershell
node --test calculator.test.mjs
```

## 部署到 GitHub Pages

1. 将本目录作为仓库根目录，将默认分支设为 `main`。
2. 推送仓库到 GitHub，并确保仓库为 Public。
3. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/(root)`，保存后等待部署。
5. 使用 GitHub Pages 给出的 `https://用户名.github.io/仓库名/` 在手机访问。

页面通过 Service Worker 缓存应用文件，首次成功打开后可离线使用；输入数据保存在浏览器 `localStorage` 中，清理浏览器站点数据会将其删除。
